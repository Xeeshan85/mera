The Problem

Manual Coordination is Slow

Current urban emergency response in Islamabad takes 10–20 minutes just to process signals and dispatch units.

Fragmented Data

Information exists in silos: social media, weather sensors, citizen calls, and global disaster alerts (GDACS) are rarely fused in real time.

The CIRO Solution

An autonomous multi-agent system that detects crises, predicts severity, and allocates resources instantaneously.

🧠 Multi-Agent

5 specialized Gemini agents orchestrated by ADK 2.0 to handle distinct phases of crisis management.

⚡ Real-Time

Firestore-powered bi-directional synchronization between the backend and Android command center.

🎯 Actionable

Not just an alert system. Generates dispatch routing, trade-off narratives, and bilingual push notifications.

System Architecture

1. Signal Ingestion: Python FastAPI collects data from multiple sources.

2. Event Bus: Cloud Pub/Sub routes signals to the Orchestrator.

3. Agent Pipeline: ADK 2.0 manages agent states and reasoning.

4. Live Data Sync: Cloud Firestore updates state instantly.

5. Command Center: Native Android (Compose) app visualizes intelligence.

The Multi-Agent Pipeline

1. Orchestrator

The brain. Uses Confidence-based Routing (0.4 = monitor, 0.8 = full dispatch) to direct traffic.

2. Detection

Classifies crisis type and resolves contradictions from noisy OSINT data.

3. Severity

Forecasts spread radius and cross-references vulnerable facilities.

4. Resource Alloc.

Matches optimal units (e.g. Drones vs Firetrucks) based on travel time and availability.

5. Notification

Generates tailored, bilingual (EN/UR) alerts for 6 distinct stakeholder profiles.
